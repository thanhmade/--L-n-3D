# Tổng hợp yêu cầu từ quá trình phát triển

Tài liệu này là **tóm tắt các yêu cầu liên quan trực tiếp tới game Nấm Lùn**, không phải bản sao nguyên văn toàn bộ hội thoại.

## Giai đoạn 1 — Khởi tạo game (14/11/2026)

- Game nhập vai hành động **nấm lùn**, nhân vật chibi anime 3D, cảnh quan cổ tích huyền ảo có cảm hứng phim hoạt hình 3D.
- Đi map, đánh quái, nhận EXP và lên cấp.
- Chuyển thành website chơi game; PC và điện thoại.
- Có 3 khu vực, kỹ năng, nhiệm vụ, quái vật, đồ nhặt và tiến trình lưu trên máy.

## Giai đoạn 2 — Phản hồi giao diện, combat (14/11/2026)

- Ảnh chụp điện thoại cho thấy bảng nhiệm vụ và HUD che nhân vật, nút dưới màn hình quá to.
- Yêu cầu có cơ chế xoay ngang màn hình khi dùng điện thoại.
- Quái ở độ khó hiện tại quá dễ; cần tăng độ thách thức.

**Đáp ứng trong v0.2.0:** HUD gọn, nhiệm vụ gấp/mở, nút xoay + API orientation lock/fallback, quái tinh anh, telegraph và 3 mức độ khó.

## Giai đoạn 3 — Bàn giao repository (14/11/2026)

- Tạo GitHub repository chuẩn, README chuyên nghiệp, skill và plugin cho công việc phát triển game.
- Repository mục tiêu: `https://github.com/thanhmade/--L-n-3D` (tên slug được dùng nguyên vẹn).

## Chưa triển khai

Mô hình 3D GLB/FBX có rig/Mixamo, cửa hàng, inventory/trang bị, boss nhiều pha, tài khoản/đồng bộ cloud, multiplayer. Những nội dung này chỉ là hướng nâng cấp, không phải tính năng hiện hữu.
