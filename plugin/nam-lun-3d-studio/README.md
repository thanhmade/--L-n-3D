# Nấm Lùn 3D Studio — Plugin ChatGPT (skills-only)

Dự án hỗ trợ phát triển game Nấm Lùn 3D bằng một kỹ năng tiếng Việt. Plugin không cài MCP server và không tự truy cập repo/triển khai website.

- Manifest: `plugin.json` và `.codex-plugin/plugin.json`.
- Skill: `skills/nam-lun-3d-dev/SKILL.md`.
- Mã nguồn game: `https://github.com/thanhmade/--L-n-3D`.
- Website: `https://nam-lun-khu-rung-tinh-linh-3d.vercel.app`.

Cài đặt: thông qua link plugin riêng được chủ sở hữu cung cấp (nếu tạo trong ChatGPT), hoặc import ZIP chứa đúng một thư mục `nam-lun-3d-studio/` ở nền tảng hỗ trợ Agent Plugins. Plugin có trạng thái riêng tư nếu không được chủ sở hữu chia sẻ.

Mẫu yêu cầu: "Dùng Nấm Lùn 3D Studio tối ưu joystick và các nút kỹ năng trên Android ngang màn hình, kiểm tra bằng chứng trước khi báo hoàn thành."
